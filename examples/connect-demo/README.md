# Milon Wallet Connect Demo

1. From the root of the `milon-wallet-sdk` checkout, run `npm ci` and `npm run build`.
2. Start the demo server with `python -m http.server 5174 -d .`.
3. Open `http://localhost:5174/examples/connect-demo/`.
4. Click **Connect Wallet** and authorize a devnet account in Milon Wallet.

The demo displays the connected account and lets you request message signing or a login signature.
